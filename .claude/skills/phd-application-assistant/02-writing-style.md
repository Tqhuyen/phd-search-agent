# 02 — Writing Style

Applies to the SOP, the CV bullets, and supervisor emails.

## Voice
- First person, active, concrete. Say what you did and what happened.
- Show, don't assert: "reproduced X, found Y" beats "I am deeply passionate about X".
- Confident but honest. State gaps plainly; never inflate.

## Hard rules
- **No em-dashes (—).** Use commas, parentheses, or two sentences.
- **No cliches:** "passionate about", "cutting-edge", "world-class", "unique
  opportunity", "I have always been fascinated". Delete on sight.
- **One idea per sentence.** PhD reviewers read fast.
- **Quantify** whenever a number exists (accuracy, speedup, size, duration).
- **Name methods and tools**, not vague skills ("trained a ViT-B/16 with LoRA on
  40k images" not "deep learning experience").

## Structure defaults
- SOP: hook, evidence, fit, contribution, close. See `04-sop-and-cv.md`.
- CV bullets: `<action verb> <what> using <method/tool>, <result>`.
- Email: greeting, one specific hook, one contribution, one ask, sign-off. See
  `05-outreach-email.md`.

## Tailoring rules
- Mirror the posting's vocabulary where your profile genuinely supports it.
- Reorder sections so the most relevant evidence is first.
- Every paragraph must answer "why this lab, why this project, why now".
- Never change a fact to fit a position. Reframe emphasis only.
